# FocusGlass: чеклист тестера

Версия для текущей передачи: `0.0.4`

Этот чеклист нужен для первого полного прохода тестера. Предыдущие изменения
ещё не тестировались, поэтому проверять надо весь пользовательский путь, а не
только последние UI-правки.

## 0. Подготовка

- Скачать `FocusGlass-0.0.4.zip`.
- Проверить контрольную сумму архива:

```sh
shasum -a 256 -c FocusGlass-0.0.4.zip.sha256
```

- Распаковать zip.
- Запустить `FocusGlass.app`.
- Записать версию macOS и способ запуска в отчёт.
- Для чистого теста можно временно убрать или переименовать
  `~/Library/Application Support/FocusGlass`.

## 1. Первый запуск и системные разрешения

- Приложение открывается сразу в главное окно.
- Нет demo-проектов и demo-задач в чистом состоянии.
- Баннер разрешений объясняет, зачем нужны Notifications и Accessibility.
- `Запросить уведомления` вызывает системный запрос macOS или понятное
  сообщение.
- `Запросить Accessibility` открывает нужный системный раздел.
- Проверки Automation не ломают приложение, если разрешение ещё не выдано.
- Повторный запуск не показывает бесконечно один и тот же системный запрос.

## 2. Главное окно

- Таймер визуально находится в центре широкого окна.
- Слева виден активный проект и `Заметки проекта`.
- Справа видна выделенная `Активная задача сессии` и список задач.
- Верхнего поля `Текущее намерение` нет.
- В карточке активного проекта нет постоянных кнопок редактирования проекта,
  счётчика задач и добавления проекта.
- Длинное название активной задачи с временем читается в 2-3 строки.
- Обычная строка задачи выглядит как одна широкая карточка, а не как три
  раздельные колонки: checkbox, карточка и кнопка редактирования.
- Средняя и компактная ширина окна не ломают порядок: таймер, контекст
  проекта, задачи.

## 3. Проекты и заметки

- Создать проект.
- Выбрать проект в выпадающем списке главного окна.
- Добавить заметки проекта в раскрываемом блоке главного окна.
- Закрыть и открыть приложение: заметки должны сохраниться.
- Открыть редактор проекта и изменить заметки там.
- Переименовать проект: задачи остаются привязанными к нему.
- Удалить проект: задачи становятся `Без проекта`.

## 4. Задачи

- Создать задачу без проекта.
- Создать больше трёх задач в одном проекте: список должен прокручиваться.
- Выбрать активную задачу, запустить таймер, затем выбрать другую задачу до
  конца сессии: время должно записаться в задачу, выбранную на старте.
- Задача с учётом времени показывает прогресс.
- Чеклист-задача не получает прогресс по времени.
- Редактирование названия, проекта, типа, оценки и статуса `Готово` работает.
- Ручной ввод минут работает рядом со степперами.

## 5. Таймеры

- Проверить Pomodoro, Countdown, Stopwatch, Flow, Timebox, Intervals.
- Start/pause/resume/reset работают.
- Skip недоступен для пресета с одним сегментом.
- Skip работает для пресета с несколькими сегментами.
- Шаг минут в степпере округляется ожидаемо: `1 -> 5 -> 10`, `6 -> 10`,
  `5 -> 1`, `0 -> 5` там, где разрешён ноль.
- Настройки пресетов сохраняются после перезапуска.

## 6. Экран итога сессии

- Завершить сессию задачи с учётом времени.
- Проверить плановое время и честное активное время фокуса.
- Проверить количество отвлечений.
- `Закрыть задачу` закрывает задачу, которая была активна на старте сессии.
- `Продолжить` оставляет эту задачу активной.
- `Следующая сессия` запускает новый таймер с той же задачей.
- Итог чеклист-задачи не показывает прогресс по времени и закрывается вручную.

## 7. Theme Studio

- Открыть Settings -> Appearance.
- Выбрать built-in theme.
- Создать копию темы.
- Изменить цвета через ColorPicker, не вводя hex вручную.
- Проверить живой предпросмотр.
- Проверить ползунки glass/motion, accent/status, foundations/readability.
- Проверить light/dark/system appearance.
- Убедиться, что нет двух одинаковых блоков живого предпросмотра или
  пояснений.
- Удалить пользовательскую тему; встроенную тему удалить нельзя.

## 8. Strict Mode

- Добавить app rule из running apps.
- Добавить правило приложения из списка запущенных приложений.
- Добавить правило приложения вручную по bundle id.
- Добавить правило сайта `youtube.com`.
- Добавить правило сайта по маске `*.reddit.com`.
- Проверить действие warn: приложение предупреждает.
- Проверить действие hide: отвлекающее окно скрывается.
- Проверить действие pause: работающий таймер становится на паузу.
- Проверить, что strict-правила по умолчанию не работают на перерыве.
- Включить Strict Mode на перерывах и проверить, что правила работают на
  перерыве.
- Проверить статус Strict Mode в главном окне, menu bar и fullscreen.

## 9. Fullscreen focus

- Открыть fullscreen mode.
- Проверить таймер, фазу и прогресс.
- Проверить панель задач.
- Проверить controls при наведении: pause/resume/reset/skip/close.
- Проверить предупреждение Strict Mode в fullscreen.
- Убедиться, что старое intention не показывается.

## 10. Menu bar HUD

- Открыть menu bar panel.
- Проверить таймер и прогресс.
- Проверить start/pause.
- Проверить toggle/status Strict Mode.
- Проверить действия fullscreen/reset/skip/open-main.
- Убедиться, что старое intention не показывается.

## 11. Отчёт

- Заполнять `tester-report-template.md`.
- Один пункт = одна проблема или UX-наблюдение.
- Для каждого пункта приложить скриншоты.
- Отдельно отметить blockers: проблемы, которые мешают дальше тестировать.
