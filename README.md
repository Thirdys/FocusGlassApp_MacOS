# FocusGlass 0.0.2 - тестовая сборка

Эта ветка предназначена только для передачи тестовой сборки. В ней нет исходного
кода проекта.

## Что скачать

- `FocusGlass-0.0.2.zip` - приложение для тестирования.
- `FocusGlass-0.0.2.zip.sha256` - файл проверки целостности zip.

## Как проверить zip

```sh
shasum -a 256 -c FocusGlass-0.0.2.zip.sha256
```

Ожидаемый результат:

```text
FocusGlass-0.0.2.zip: OK
```

## Как запустить

1. Скачать `FocusGlass-0.0.2.zip`.
2. Распаковать zip.
3. Запустить `FocusGlass.app`.
4. Если macOS предупредит, что приложение скачано из интернета, подтвердить
   запуск вручную.

Сборка unsigned, то есть она не подписана Developer ID и не notarized. Это
нормально для текущего ручного теста.
